# Root Route Surface Brief

- Scope: anonymous `/` route only. Mode: Persuade.
- Audience: engineering/project leads and company managers evaluating whether
  HumanThread can keep human and AI delivery work in one traceable context.
- Job: understand the product mechanism, see a believable delivery loop, then
  log in or create an account.
- Proof: Space and Project context feeds a unified Task; an Agent or Loop runs;
  a human confirms; the outcome and supporting document remain traceable.
- Constraints: authenticated visitors redirect to `/dashboard`; anonymous
  rendering remains database-independent without an auth Cookie; no customer,
  benchmark, price, or unsupported capability claims.
- Direction: Delivery Dispatch Graph. The first viewport pairs a five-column
  product offer with a seven-column delivery run so the live demonstration is
  the dominant proof rather than a thin route below the copy.
- Memorable moment: one signal line advances once through assignment, automated
  execution, human confirmation, and recorded outcome. Later scrolling explains
  each governing layer without hijacking native scroll.
- Mobile: the running graph becomes a vertical route in document order.
- Reduced motion: show the complete route and final states immediately.
- Composition approval: the user confirmed the Delivery Dispatch Graph
  direction and the combined automatic-plus-scroll demonstration strategy.
- Asset constraint: the current harness exposes no callable built-in image
  generator, so the composition remains semantic HTML/CSS with the existing
  brand assets rather than a rasterized UI mockup.
