# Web 工作台页面

代码位于 apps/web/src/features 与 components，覆盖 dashboard、projects、tasks、documents、notifications、reports、agents、templates、team 等工作区。页面通过查询客户端读取 API。

`/live-sessions` 使用全高 TUI 工作区，不渲染页面级大标题。桌面端保留会话列表、真实 xterm 终端和执行上下文三栏；平板收起右侧上下文，移动端通过会话与上下文抽屉操作。终端仍通过 LiveSession Relay 使用一次性票据、控制租约、二进制输出和尺寸同步，页面不保存会话正文。

文档工作区以服务端目录树为事实来源，同路由的空间软切换会直接替换客户端目录实例，不要求刷新页面。目录、正文和修订侧栏共享 `minmax(0,1fr)` 全高布局。正文仅保留查看与编辑两个状态：查看态渲染 Markdown，编辑态使用 CodeMirror，保存成功后回到查看。受保护的 `.xmind` 与 `.vsdx` 附件链接在查看态渲染只读导图预览，解析受限时回退为下载。
