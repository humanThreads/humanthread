# 主框架

HumanThread 是面向 AI 辅助工作的任务调度与人机协同平台。仓库为 pnpm monorepo，运行面由 Web、桌面 Local Agent、服务端 Worker 和 CLI 组成。

## 模块分层与索引

1. [Web](./web/README.md)：工作台、API、认证与会话。
2. [Local Agent](../local-agent-electron-migration.md)：桌面工作台、Loop 执行、离线与 Outbox。
3. [编排](./编排/README.md)：Workflow Core、Orchestration Core、状态与门禁。
4. [同步](./同步/README.md)：项目 Loop 同步、共享协议。
5. [数据](./数据/README.md)：数据库访问、Schema 与迁移。
6. [Worker](./worker/README.md)：编排 Worker、Docker、Kubernetes、Worker Pool。
7. [CLI](./cli/README.md)：CLI Wrapper 与发布打包。
8. [基础设施](./基础设施/README.md)：镜像部署与发布流水线。

## 核心数据流

Web 创建任务 → API 权限与版本校验 → 数据库事务和领域事件 → Loop 选择执行目标 → Local Agent 或 Worker 执行 → 日志、结果和验收证据回写 → Web 展示状态。网络中断由本地快照与 outbox 重试恢复。

## 依赖边界

UI 不直接访问数据库；核心包不依赖平台 IO；跨端协议集中在 shared；服务端是任务状态权威来源；凭据由环境变量、CI 凭据库或 Kubernetes Secret 提供。

## 验证和维护

受影响包必须运行 test、typecheck、build；跨模块变更需运行直接消费者类型检查。新增接口、字段、状态、配置或依赖必须在同一任务更新对应模块文档。
